# Security Policy

Plugboard is a static, client-side directory (a single HTML page served via
GitHub Pages). It has no backend, no accounts, and collects no personal data,
so its own attack surface is minimal.

## Reporting a concern

If you find something worth flagging — for example:

- a link in the directory that points to a malicious, hijacked, or
  impersonating site,
- an add-on listed here that turns out to be unsafe, or
- any issue with the page itself,

please report it privately using GitHub's
[**Report a vulnerability**](https://github.com/plumbgoat/ai-plugin-directory/security/advisories/new)
feature, or open a regular issue if it isn't sensitive.

Please don't disclose a serious issue publicly until it's had a chance to be
addressed.

## Note on listed add-ons

Plugboard links to third-party plugins and MCP servers it does not control.
Inclusion here is not a security endorsement — review and trust any add-on
yourself before installing it, the same as you would for anything you run.
