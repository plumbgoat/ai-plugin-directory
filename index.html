How this list works. A curated selection, not an exhaustive dump — the point is to help you pick, not to list everything. Universal (MCP) add-ons run in any MCP-capable tool (Claude Code, Cursor, Windsurf, and more); Claude add-ons install in Claude Code. Descriptions are drawn from each tool's official listing; tool availability is best-effort and changes fast. Plugins marked plumbgoat are ours.
