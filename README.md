# Plugboard

**A curated, cross-tool directory of AI coding add-ons — organized by the job
you're doing, not by which company made them.**

Most directories list *everything* and sort by vendor category (Database,
Security, Monitoring…). Nobody wakes up needing "a Monitoring plugin" — they
need to *debug faster*, *write tests*, *ship without breaking prod*.
Plugboard sorts by that: your job first, then a short hand-picked shortlist,
tagged with which AI tool it works in.

🔌 **[View the directory →](https://claude.ai/code/artifact/0e23109e-f0b2-44d9-91df-c512802c7f6b)**

## What's inside

Add-ons grouped by developer job:

- **Debug & fix** · **Test** · **Ship & review** · **Incidents & ops**
- **Plan & track** · **Prompts & context** · **Data & backend** · **Build your own**

Each entry is tagged:

- 🟣 **Universal (MCP)** — runs in any MCP-capable tool: Claude Code, Cursor,
  Windsurf, and more.
- 🟠 **Claude** — installs in Claude Code.

Use the **"Works in"** filter to see only what runs in *your* tool. (Pick
Cursor and you'll see the universal MCP servers — the ones that actually work
there.)

## Philosophy

- **Curated, not exhaustive.** The value is helping you pick, not listing
  2,000 things.
- **By job, not by vendor.** Organized around what you're trying to get done.
- **Honest.** Descriptions come from each tool's official listing; tool
  availability is best-effort and moves fast. No invented ratings.
